# Lucky Merge Defense — 디자인 시스템

## 1. 컨셉
"밤의 던전 카지노". 어두운 남색 바탕 위에 **금색(골드)** 과 **등급 색**이 빛나는, 뽑기의 설렘을 강조하는 비주얼.
정보 밀도가 높은 디펜스 게임이므로 **HTML UI(패널/버튼)** 와 **Canvas(보드)** 를 분리해 가독성과 터치 조작성을 확보한다.

## 5. 컴포넌트
- **버튼**: 둥근 모서리 12px, 기본 `--panel-2`, 주요 CTA는 골드 그라데이션 + 어두운 글자. 비활성은 투명도 0.45.
- **등급 뱃지**: 등급 색 배경 + 흰 글자, 신화는 `box-shadow` 글로우 펄스.
- **유닛 칩(보드)**: 등급색 테두리 원 + 치비 스프라이트(원 지름의 1.0배), 우상단 스택 수(×2, ×3), 좌하단 **속성 배지**(속성색 원 + 한 글자), 3스택은 금색 테두리 점멸("합성 가능").
- **속성 뱃지(HTML)**: `.badge.elem` — 속성색 배경 + 어두운 글자. HUD(이번 라운드 몬스터 속성), 유닛 카드, 레시피, 속성 탭, 타이틀에 공통 사용.
- **플레이어 라벨**: `.plabel` P1 금색 / P2 파랑(`#4ea8ff`). 보드 상단·유닛 카드·결과 화면·패널 전환 버튼에서 동일.
- **토스트**: 하단 중앙, 1.4초 페이드. 소환 결과/오류 메시지.
- **배너**: 라운드 시작·보스 등장·승/패. 중앙 큰 글자, 0.8초 등장 애니메이션.

## 6. 모션
- 소환: 칸에서 등급색 링 확산(0.4s). 전설 이상은 보드 비네트 플래시.
- 합성: 3개 칩이 중앙으로 수축 → 새 칩 팝(스케일 0→1.2→1).
- 공격: 유닛이 대상 방향으로 돌진(최대 0.16칸)하고 가로 +14% / 세로 -10% 스쿼시, 0.28초 sin 곡선으로 복귀. 처음 75% 구간은 무기 공격 프레임. 대상이 왼쪽이면 스프라이트 좌우 반전.
- 정령 부유: 칩 전체가 -0.02칸 기준으로 ±0.022칸 떠다니고(칸마다 위상 차), 바닥 타원 그림자는 높을수록 작아진다. 칩 뒤에 속성색 라디얼 오라(α .33→0), 앞에 속성 입자 3개가 1.5rad/s로 궤도. 불은 솟아오르는 불씨, 번개는 깜빡이는 스파크, 빛은 트윙클 십자.
- 스킬 발동: 속성색 링 확산(0.55초) + 입자 6개 방사, 번개는 위에서 내리꽂는 번개 선, 땅은 바닥 균열, 빛은 흰 섬광. 몬스터 상태: 둔화 파랑 틴트 / 저주 보라 틴트 / 속박 발밑 덩굴 링 / 스턴 머리 위 스파크 회전. 스킬명 소형 텍스트.
- 드래그: 원래 칸 α .35, 고스트 칩 1.15배 + 등급색 그림자, 포인터 위 0.3r 지점에 떠 있음. 대상 칸은 이동/겹치기 초록(`--ok`), 교환 노랑(`--gold`) 채움+테두리+라벨.
- 몬스터 걷기: 상하 바운스 0.03칸 + ±0.08rad 기울기(개체마다 위상 차). 보스는 숨쉬기 스케일 ±3%.
- 피격: 몬스터 흰색 플래시 2프레임, 사망 시 작은 파티클 6개. 속성 유리 타격 시 노란 "약점!" 소형 텍스트.
- 몬스터 90+ 경고: 보드 테두리 `--danger` 펄스.

## 7. 접근성 / 반응형
- 모든 조작은 터치 1탭으로 가능(드래그는 선택 사항). 버튼 최소 44×44px.
- `prefers-reduced-motion` 시 펄스/파티클 최소화.
- 가로 모드 PC: 보드 최대 640px, 하단 패널은 그대로 아래 배치(스크롤 없이 1080p에 전부 노출).

## 8. 치비 픽셀 아트 스프라이트 (`js/sprites.js`)
- 모든 스프라이트 **16×16**. 스타일 키워드: **아기자기** — 머리 12×9에 몸 6×4(머리:몸 ≈ 2:1), 2×2 큰 눈(좌상단 흰 하이라이트), 볼터치 2픽셀, 점 입. 외곽선 `o = #2b2340`(보라빛 검정, 순검정보다 부드러움).
- **인간형 16종**은 공통 `TEMPLATE` 위에 레이어를 찍는 합성 방식: `back`(날개·망토) → 템플릿 → `hat`(후드·뾰족모자·왕관·밀짚모자·헬멧·뿔·후광·복면·두건·깃털·티아라) → `weapon`. 유닛 정의는 색 3개(머리카락 H / 옷 B / 신발 f)와 레이어 목록뿐이라 신규 유닛 추가가 쉽다. 레이어의 `'x'`는 아래 픽셀 지우기(모자 실루엣용).
- **무기 레이어는 idle / attack 두 포즈**: 활은 당긴 자세 + 날아가는 화살, 검은 대각 베기, 창·총은 전방 찌르기/사격(총구 섬광), 지팡이·완드는 들어올림 + 반짝임, 불꽃은 커진 화염.
- **속성 표현**: 눈(E)과 허리띠(d)가 `ELEMENTS[*].eye`(배지색보다 진한 변형: 빛은 금색, 바람은 청록) → 한눈에 속성 구분. 배지 색은 `ELEMENTS[*].color`.
- **비인간형 7 + 몬스터 3 + 보스 4**는 개별 그리드(슬라임·독사·번개 구름 정령·불사조·세계수·혼돈의 군주 / 그렘린·늑대·바위골렘 / 오우거·흑룡·리치 킹·마왕)로 같은 눈·볼터치 규칙을 따라 통일감 유지.
- 렌더는 `imageSmoothingEnabled = false` + CSS `image-rendering: pixelated`. 피격 시 흰색 단색 틴트 변형. 캐시 키 `key:px:tint:frame`.
- 검증: `node tools/check-sprites.mjs [key]`(색 누락·범위 초과 검출, ASCII 출력) · 미리보기: `tools/sprites-sheet.html`(대기/공격 프레임 나란히).
