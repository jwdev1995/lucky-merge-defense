# Lucky Merge Defense — 디자인 시스템

## 1. 컨셉
"밤의 던전 카지노". 어두운 남색 바탕 위에 **금색(골드)** 과 **등급 색**이 빛나는, 뽑기의 설렘을 강조하는 비주얼.
정보 밀도가 높은 디펜스 게임이므로 **HTML UI(패널/버튼)** 와 **Canvas(보드)** 를 분리해 가독성과 터치 조작성을 확보한다.

## 3. 타이포그래피
- 시스템 폰트 스택: `"Pretendard", "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif` (외부 로드 없음)
- 숫자(골드/타이머)는 `font-variant-numeric: tabular-nums` 로 흔들림 방지
- 크기: HUD 13~14px, 버튼 15px, 제목 22px, 배너 28px

## 5. 컴포넌트
- **버튼**: 둥근 모서리 12px, 기본 `--panel-2`, 주요 CTA는 골드 그라데이션 + 어두운 글자. 비활성은 투명도 0.45.
- **등급 뱃지**: 등급 색 배경 + 흰 글자, 신화는 `box-shadow` 글로우 펄스.
- **유닛 칩(보드)**: 등급색 테두리 원 + 픽셀 스프라이트, 우상단 스택 수(×2, ×3), 3스택은 금색 테두리 점멸("합성 가능").
- **토스트**: 하단 중앙, 1.4초 페이드. 소환 결과/오류 메시지.
- **배너**: 라운드 시작·보스 등장·승/패. 중앙 큰 글자, 0.8초 등장 애니메이션.

## 6. 모션
- 소환: 칸에서 등급색 링 확산(0.4s). 전설 이상은 보드 비네트 플래시.
- 합성: 3개 칩이 중앙으로 수축 → 새 칩 팝(스케일 0→1.2→1).
- 피격: 몬스터 흰색 플래시 2프레임, 사망 시 작은 파티클 6개.
- 몬스터 90+ 경고: 보드 테두리 `--danger` 펄스.

## 7. 접근성 / 반응형
- 모든 조작은 터치 1탭으로 가능(드래그 불필요). 버튼 최소 44×44px.
- `prefers-reduced-motion` 시 펄스/파티클 최소화.
- 가로 모드 PC: 보드 최대 640px, 하단 패널은 그대로 아래 배치(스크롤 없이 1080p에 전부 노출).

## 8. 픽셀 아트 스프라이트 (`js/sprites.js`)
- 유닛 12×12, 보스 16×16 문자열 그리드. `'.'`은 투명, `o`는 공통 외곽선(`#1b1b2f`), `W/k/s/r/y`는 공통 팔레트(흰색·검정·피부·빨강·금색), 나머지 문자는 스프라이트별 팔레트.
- 등급이 오를수록 실루엣이 커지고 색이 선명해진다: 일반은 2~3색의 작은 인간형, 영웅은 원소 생물, 전설은 장식(뿔·후광·지팡이), 신화는 보드 전체에서 눈에 띄는 보색 대비.
- 렌더는 `imageSmoothingEnabled = false` + CSS `image-rendering: pixelated`로 픽셀이 뭉개지지 않게 확대. 피격 시 흰색 단색 틴트 변형을 2프레임 표시.
- 미리보기: `tools/sprites-sheet.html`
