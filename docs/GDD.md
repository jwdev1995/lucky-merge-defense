# Lucky Merge Defense — 게임 기획서 (GDD)

> 모바일 랜덤 디펜스 **운빨존많겜(Lucky Defense)** 의 핵심 재미(운에 맡기는 소환 → 같은 유닛 3개 합성 → 상위 등급 랜덤 획득 → 신화 레시피)를
> 브라우저(PC/모바일)에서 즐길 수 있도록 재해석한 **싱글플레이 웹 디펜스 게임**입니다.
> 원작의 에셋·이름·수치는 사용하지 않으며, 시스템은 독자적으로 설계했습니다.

## 1. 한 줄 컨셉
"뽑기는 운, 배치는 실력." 루프를 도는 몬스터가 **100마리**를 넘기 전에, 랜덤 소환과 합성으로 덱을 키워 **40라운드(보스 4회)** 를 버텨라.

## 2. 플랫폼 / 기술
- 브라우저(PC·모바일) 정적 웹 — Vanilla JS(ES Modules) + Canvas 2D + HTML UI
- 외부 라이브러리·에셋·빌드 도구 없음. 유닛/몬스터 그래픽은 이모지 + 코드 드로잉, 효과음은 WebAudio 합성
- 세로형(모바일) 우선 레이아웃, PC에서는 가운데 정렬 카드 형태

## 3. 코어 루프
```
골드 획득(처치/라운드 보상) → 소환(20G, 등급 랜덤) → 같은 유닛 3개 = 합성 → 상위 등급 랜덤 유닛
      ↑                                                                   ↓
   몬스터 처치  ←  배치/이동/강화/룰렛/신화 레시피 조합  ←  덱 성장 ──────────┘
```

## 4. 맵 & 배치
- 보드: 8×5 칸. 가운데 **6×3 = 18칸** 유닛 배치 그리드, 둘레 1칸 폭의 **루프 경로**(시계방향).
- 몬스터는 좌상단에서 등장해 루프를 **무한히 돈다**. 처치되지 않으면 계속 쌓인다.
- 한 칸에는 **같은 종류 유닛만 최대 3개**까지 겹쳐 놓을 수 있다(스택). 스택 수만큼 공격력이 배가된다.
- 유닛 보유 상한 **20개**(스택 포함 개수).

## 5. 소환
| 항목 | 값 |
|---|---|
| 비용 | 20 골드 (고정) |
| 확률 | 일반 68% / 희귀 24% / 영웅 7% / 전설 1% |
| 배치 | 같은 유닛이 있는 미완성 스택 우선 → 없으면 빈 칸 랜덤 |
| 실패 | 빈 칸 없음 또는 유닛 20개 초과 시 소환 불가(골드 미차감) |

## 6. 합성 (Merge)
- 같은 유닛 **3개 스택** → 「합성」 → 3개 소멸, **다음 등급 랜덤 유닛 1개**가 그 자리에 생성.
- 일반→희귀→영웅→전설. **전설 3개 합성은 불가**(신화는 레시피로만).
- 합성은 운이지만, "무엇을 노릴지"는 레시피 보드로 설계할 수 있다.

## 7. 등급 & 유닛 (총 22종)
| 등급 | 색 | 유닛 | 특징 |
|---|---|---|---|
| 일반 | 회색 | 궁수, 검병, 창병, 슬라임, 농부 | 단일 공격. 입문 라인 |
| 희귀 | 파랑 | 마법사(광역), 사냥꾼(연사), 얼음술사(둔화), 석궁병(관통), 도적(치명타) | 상태이상 시작 |
| 영웅 | 보라 | 화염술사(광역+화상), 저격수(장거리 고화력), 번개술사(연쇄), 암살자(고치명타), 독사(중독) | 전투 핵심 |
| 전설 | 주황 | 드래곤 기사(대광역), 대마법사(광역 폭발), 신궁(초연사), 시간술사(광역 둔화) | 덱 완성 |
| 신화 | 빨강(발광) | 불사조, 혼돈의 군주, 천사장, 세계수 | 레시피 전용 |

### 신화 레시피 (보드 위의 지정 유닛 각 1개를 소모)
| 신화 | 재료 | 능력 |
|---|---|---|
| 불사조 | 드래곤 기사 + 화염술사 + 번개술사 | 광역 화상 + 연쇄 |
| 혼돈의 군주 | 대마법사 + 암살자 + 독사 | 초고치명타 광역 |
| 천사장 | 신궁 + 저격수 + 얼음술사 | 초장거리·연사·둔화 |
| 세계수 | 시간술사 + 대마법사 + 독사 | 전체 둔화 + 광역 중독 |

## 8. 라운드 & 몬스터
- 라운드 길이 **20초**, 총 **40라운드**. 10/20/30/40 라운드는 **보스 라운드**.
- 일반 라운드: `12 + 라운드` 마리(최대 40)가 첫 10초 동안 분산 등장. 체력은 `base × 1.2^(라운드-1)`.
- 몬스터 종류: 일반(👾), 빠름(🐺, 속도 1.6배·체력 0.6배), 방패(🪨, 체력 2.2배·속도 0.7배·피해 감소), 보스(👹/🐉/💀/👑).
- **보스**: 제한 시간(라운드 20초) 내 처치 실패 → 패배. 처치 시 골드 +(100 + 라운드×5) 및 보상 상자.
- **패배**: 필드 몬스터 ≥ 100마리 또는 보스 시간 초과.
- **승리**: 40라운드 보스 처치.

## 9. 경제
| 수입 | 값 |
|---|---|
| 일반 몬스터 처치 | 1G (방패형 2G) |
| 라운드 종료 보상 | 15 + 라운드 G |
| 보스 처치 | 100 + 라운드×5 G |
| 시작 골드 | 120G |

| 지출 | 값 |
|---|---|
| 소환 | 20G |
| 행운의 룰렛 | 30G → 10G(35%) / 60G(10%) / 희귀 유닛(28%) / 영웅 유닛(17%) / 전설 유닛(5%) / 꽝(5%) |
| 등급 강화 | 등급별 공격력 +15%/Lv. 비용: 일반 30·희귀 60·영웅 120·전설 250·신화 400 G (Lv마다 ×1.5) |
| 판매 | 소환가 환급: 일반 10 / 희귀 25 / 영웅 60 / 전설 150 / 신화 300 |

## 10. 전투 규칙
- 유닛은 사거리 내에서 **가장 많이 진행한(가장 오래 산)** 몬스터를 우선 공격.
- 공격 타입: 단일 / 광역(반경) / 연쇄(2~3체) / 관통 / 둔화 / 중독·화상(DoT) / 치명타(×2.5).
- 스택 n개 = 피해 ×n. 등급 강화 Lv = 피해 ×(1 + 0.15×Lv).
- 방패형은 피해 -20%(최소 1).

## 11. UI / 조작
- 상단 HUD: 골드, 라운드/타이머, 몬스터 수 게이지(100 임계), 유닛 수(x/20), 보스 체력바.
- 하단 패널: 「소환」, 「룰렛」, 「강화」, 「레시피」 탭.
- 칸 터치/클릭 → 유닛 선택 → 정보 카드(판매/합성). 다른 칸 터치 → **이동(또는 교환)**.
- 키보드: `Q` 소환, `R` 룰렛, `ESC` 선택 해제, `P` 일시정지, `M` 음소거, `1~3` 배속(1×/2×/3×).

## 12. 연출
- 소환 시 등급별 색 플래시·사운드(전설 이상은 보드 전체 발광), 합성 시 파티클.
- 보스 등장 배너, 몬스터 90마리 이상 시 경고(붉은 테두리 점멸).
- 결과 화면: 도달 라운드, 처치 수, 최고 등급 유닛, 최고 기록(로컬 저장).

## 13. 밸런스 메모
- 밸런스 수치는 모두 `js/config.js` 단일 소스에서 관리.
- 목표 체감: 10라운드 보스 = 영웅 2~3개 덱, 20라운드 = 전설 1개, 30라운드 = 신화 1개, 40라운드 = 신화 2개 + 강화.
- 헤드리스 시뮬레이터(`tools/sim.mjs`)로 "평균 골드 → 기대 DPS 곡선"을 라운드별 몬스터 체력과 비교하여 튜닝.
