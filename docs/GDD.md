# Lucky Merge Defense — 게임 기획서 (GDD)

> 모바일 랜덤 디펜스 **운빨존많겜(Lucky Defense)** 의 핵심 재미(운에 맡기는 소환 → 같은 유닛 3개 합성 → 상위 등급 랜덤 획득 → 신화 레시피)를
> 브라우저(PC/모바일)에서 즐길 수 있도록 재해석한 **웹 디펜스 게임**입니다. 1인 플레이와 한 기기 2인 협동을 지원합니다.
> 원작의 에셋·이름·수치는 사용하지 않으며, 시스템은 독자적으로 설계했습니다.

## 1. 한 줄 컨셉
"뽑기는 운, 배치는 실력." 루프를 도는 몬스터가 **100마리**를 넘기 전에, 랜덤 소환과 합성으로 덱을 키워 **40라운드(보스 4회)** 를 버텨라.

## 2. 플랫폼 / 기술
- 브라우저(PC·모바일) 정적 웹 — Vanilla JS(ES Modules) + Canvas 2D + HTML UI
- 외부 라이브러리·에셋·빌드 도구 없음. 유닛/몬스터는 16×16 치비 픽셀 아트를 코드로 생성(공통 템플릿 + 모자/무기 레이어), 효과음은 WebAudio 합성
- 세로형(모바일) 우선 레이아웃, PC에서는 가운데 정렬 카드 형태

## 3. 코어 루프
```
골드 획득(처치/라운드 보상) → 소환(20G, 등급 랜덤) → 같은 유닛 3개 = 합성 → 상위 등급 랜덤 유닛
      ↑                                                                   ↓
   몬스터 처치  ←  배치/이동/강화/룰렛/신화 레시피 조합  ←  덱 성장 ──────────┘
```

## 4. 맵 & 배치
- 보드: 8×5 칸. 가운데 **6×3 = 18칸** 유닛 배치 그리드, 둘레 1칸 폭의 **루프 경로**(시계방향).
- 몬스터는 좌상단에서 등장해 루프를 **무한히 돈다**. 처치되지 않으면 계속 쌓인다.
- 한 칸에는 **같은 종류 유닛만 최대 3개**까지 겹쳐 놓을 수 있다(스택). 스택 수만큼 공격력이 배가된다.
- 유닛 보유 상한 **20개**(스택 포함 개수).

## 5. 소환
| 항목 | 값 |
|---|---|
| 비용 | 20 골드 (고정) |
| 확률 | 일반 68% / 희귀 24% / 영웅 7% / 전설 1% |
| 배치 | 같은 유닛이 있는 미완성 스택 우선 → 없으면 빈 칸 랜덤 |
| 실패 | 빈 칸 없음 또는 유닛 20개 초과 시 소환 불가(골드 미차감) |

## 6. 합성 (Merge)
- 같은 유닛 **3개 스택** → 「합성」 → 3개 소멸, **다음 등급 랜덤 유닛 1개**가 그 자리에 생성.
- 일반→희귀→영웅→전설. **전설 3개 합성은 불가**(신화는 레시피로만).
- 합성은 운이지만, "무엇을 노릴지"는 레시피 보드로 설계할 수 있다.

## 7. 등급 & 유닛 (총 22종)
| 등급 | 색 | 유닛 | 특징 |
|---|---|---|---|
| 일반 | 회색 | 궁수, 검병, 창병, 슬라임, 농부 | 단일 공격. 입문 라인 |
| 희귀 | 파랑 | 마법사(광역), 사냥꾼(연사), 얼음술사(둔화), 석궁병(관통), 도적(치명타) | 상태이상 시작 |
| 영웅 | 보라 | 화염술사(광역+화상), 저격수(장거리 고화력), 번개술사(연쇄), 암살자(고치명타), 독사(중독) | 전투 핵심 |
| 전설 | 주황 | 드래곤 기사(대광역), 대마법사(광역 폭발), 신궁(초연사), 시간술사(광역 둔화) | 덱 완성 |
| 신화 | 빨강(발광) | 불사조, 혼돈의 군주, 천사장, 세계수 | 레시피 전용 |

### 신화 레시피 (보드 위의 지정 유닛 각 1개를 소모)
| 신화 | 재료 | 능력 |
|---|---|---|
| 불사조 | 드래곤 기사 + 화염술사 + 번개술사 | 광역 화상 + 연쇄 |
| 혼돈의 군주 | 대마법사 + 암살자 + 독사 | 초고치명타 광역 |
| 천사장 | 신궁 + 저격수 + 얼음술사 | 초장거리·연사·둔화 |
| 세계수 | 시간술사 + 대마법사 + 독사 | 전체 둔화 + 광역 중독 |

## 7-1. 속성 (Element)
- 7속성: **불 → 바람 → 땅 → 번개 → 물 → 불** (순환 상성), **빛 ↔ 어둠**(서로 유리).
- 모든 유닛은 속성 1개를 가진다(`config.js` `element`). 스프라이트의 눈·허리띠 색과 칩 좌하단 배지로 표시.
- 피해 배율: 유리 **×1.3**, 불리 **×0.9**, 그 외 ×1. DoT(중독·화상)에도 적용. 유리 타격 시 "약점!" 텍스트.
- 몬스터 속성은 라운드마다 순환(불·물·바람·땅·번개·빛·어둠), 보스는 고유 속성(오우거 땅 / 흑룡 불 / 리치 킹 어둠 / 마왕 번개).
- 의도: 매 라운드 "지금 어떤 유닛을 앞에 둘까"라는 배치 판단을 추가하되, 봇 시뮬 승률이 속성 없는 경우와 비슷하게(약 25%) 유지되도록 배율을 작게 둔다.

### 속성 스킬 (`config.js` `ELEMENT_SKILLS`)
유닛이 **주 대상**을 타격할 때마다 확률로 발동. 보스에게는 스턴·속박·밀치기가 30%만 적용(`BOSS_CC_MULT`).
| 속성 | 스킬 | 확률 | 효과 | 이펙트 |
|---|---|---|---|---|
| 불 | 화상 | 25% | 2초간 초당 공격력 30% 추가 피해 | 주황 링 + 솟는 불씨 |
| 물 | 둔화 | 25% | 2초간 이동속도 -40% | 파란 링 + 물방울, 몬스터 파란 틴트 |
| 바람 | 밀치기 | 20% | 경로 뒤로 0.7칸 | 청록 바람결 |
| 땅 | 속박 | 20% | 1초 이동 불가 | 갈라진 바닥 + 발밑 덩굴 링 |
| 번개 | 감전 | 20% | 0.5초 스턴 + 인접 1체에 피해 50% 전이 | 하늘에서 내리꽂는 번개, 머리 위 스파크 |
| 빛 | 성광 | 20% | 즉시 공격력 60% 추가 피해 | 흰 섬광 + 반짝임 |
| 어둠 | 저주 | 20% | 3초간 받는 피해 +25% | 보라 안개, 몬스터 보라 틴트 |

## 7-2. 2인 협동 (한 기기)
- 타이틀에서 「2인 협동」 선택 → 보드 2개(P1/P2)가 세로(모바일) 또는 가로(PC ≥ 900px)로 배치된다.
- 각 플레이어는 **골드·유닛·강화·레시피가 독립**. 소환/룰렛 버튼과 단축키(P1 `Q`/`R`, P2 `U`/`I`)도 각자.
- **공유**: 라운드 시계, 몬스터 속성, 몬스터 수(두 보드 합산, 한도 **160**).
- **보스**: 두 보드에 각각 등장(체력 ×0.8). **둘 다** 제한 시간 안에 잡아야 다음 라운드. 한쪽이라도 실패하면 공동 패배.
- **골드 지원**: 💝 버튼으로 상대에게 20G 전달(협동의 핵심 상호작용).
- 결과 화면은 P1/P2 통계를 따로 보여주고 최고 기록은 1인/2인 별도 저장.

## 8. 라운드 & 몬스터
- 라운드 길이 **20초**, 총 **40라운드**. 10/20/30/40 라운드는 **보스 라운드**.
- 일반 라운드: `12 + 라운드` 마리(최대 40)가 첫 10초 동안 분산 등장. 체력은 `base × 1.21^(라운드-1)`.
- 몬스터 종류: 일반(👾), 빠름(🐺, 속도 1.6배·체력 0.6배), 방패(🪨, 체력 2.2배·속도 0.7배·피해 감소), 보스(👹/🐉/💀/👑).
- **보스**: 제한 시간(라운드 20초) 내 처치 실패 → 패배. 처치 시 골드 +(100 + 라운드×5) 및 보상 상자.
- **패배**: 필드 몬스터 ≥ 100마리(2인: 합산 160) 또는 보스 시간 초과.
- **승리**: 40라운드 보스 처치(2인: 두 보드 모두).

## 10. 전투 규칙
- 유닛은 사거리 내에서 **가장 많이 진행한(가장 오래 산)** 몬스터를 우선 공격.
- 공격 타입: 단일 / 광역(반경) / 연쇄(2~3체) / 관통 / 둔화 / 중독·화상(DoT) / 치명타(×2.5).
- 스택 n개 = 피해 ×n. 등급 강화 Lv = 피해 ×(1 + 0.15×Lv).
- 방패형은 피해 -20%(최소 1).
- 속성 상성 배율(7-1) 적용.

## 11. UI / 조작
- 상단 HUD(공용): 라운드/타이머, 이번 라운드 몬스터 속성, 몬스터 수 게이지, 보스 체력바.
- 플레이어 블록(1~2개): P 라벨, 골드, 유닛 수, 보드, 「소환」「룰렛」(2인은 「💝 지원」).
- 하단 패널: 「강화」「신화 레시피」「속성」「도움말」 탭. 2인은 P1/P2 전환 버튼.
- 칸 터치/클릭 → 유닛 선택 → 정보 카드(판매/합성/속성 스킬). 다른 칸 터치 → **이동(또는 교환)**.
- **드래그**: 유닛을 8px 이상 끌면 드래그 시작. 유닛이 포인터를 따라오고 원래 칸은 반투명, 놓을 칸에 「이동/겹치기/교환」 라벨과 색(초록/노랑) 강조. 보드 밖에 놓으면 취소.
- 키보드: P1 `Q` 소환 `R` 룰렛, P2 `U` 소환 `I` 룰렛, `E` 합성, `S` 판매, `ESC` 선택 해제, `P` 일시정지, `M` 음소거, `1~3` 배속(1×/2×/3×).

## 12. 연출
- 소환 시 등급별 색 플래시·사운드(전설 이상은 보드 전체 발광), 합성 시 파티클.
- **공격 모션**: 발사 순간 유닛이 대상 방향으로 0.28초 돌진 후 복귀(가로로 늘어나는 스쿼시), 무기 레이어가 공격 포즈로 교체, 대상이 왼쪽이면 좌우 반전. 대기 중엔 느린 숨쉬기 바운스.
- 몬스터는 걷기 바운스·기울기, 보스는 숨쉬기 스케일. 피격 시 흰색 실루엣 플래시.
- **정령 연출**: 유닛은 칸 위에 떠 있고(바닥 타원 그림자, 높이에 따라 크기 변화) 속성색 방사형 오라 위에 속성별 입자 3개가 궤도를 돈다.
- **배경**: 밤의 초원. 잔디 타일(체커 + 풀잎 플렉 + 꽃), 자갈 돌길(루프), 보드 둘레 여백에 나무 4그루·덤불·바위·등불 2개(불빛 깜빡임). 결정적 난수로 한 번만 그려 캐시.
- 보스 등장 배너, 몬스터 90마리 이상 시 경고(붉은 테두리 점멸).
- 결과 화면: 도달 라운드, 처치 수, 최고 등급 유닛, 최고 기록(로컬 저장).

## 13. 밸런스 메모
- 밸런스 수치는 모두 `js/config.js` 단일 소스에서 관리.
- 목표 체감: 10라운드 보스 = 영웅 2~3개 덱, 20라운드 = 전설 1개, 30라운드 = 신화 1개, 40라운드 = 신화 2개 + 강화.
- 헤드리스 시뮬레이터(`tools/sim.mjs [판수] [인원]`)로 튜닝. 속성 스킬 추가 전 봇 승률은 1인 24% / 2인 28%였고, 스킬 추가로 43%까지 올라가 체력 성장률 1.2 → 1.21, 리치 킹 30000 → 34000, 마왕 95000 → 120000, 협동 한도 150 → 160으로 조정해 1인 26%(80판) / 2인 18%(80판)로 맞췄다. 성장률만 올리면 2인이 급격히 어려워진다(1.23에서 2인 1%): 두 보드 합산 한도에 체력 증가가 그대로 쌓이기 때문. 속성 배율을 끄면 1인 30%로, 불리 배율 0.85에서는 18%로 떨어져 0.9로 결정.
